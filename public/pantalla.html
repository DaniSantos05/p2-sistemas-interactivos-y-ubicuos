Modo tilt

Instrucciones para usar el modo de control por inclinación (solo para el menú de opciones desplegables)

  • Inclina el dispositivo hacia la izquierda para abrir el menú de opciones.
  • Inclina el dispositivo hacia arriba o abajo para moverte.
  • Inclina el dispositivo hacia la izquierda para seleccionar (click).
  • Inclina el dispositivo hacia la derecha para retroceder / salir.
  • Mantén el dispositivo recto para evitar cambios erráticos.

Modo gestos

Instrucciones para usar el control por gestos con la cámara frontal (solo para el menú de opciones desplegables)

  • Mueve la mano frente a la cámara frontal para que pueda detectarse.
  • Desplaza la mano hacia la izquierda para abrir el menú de opciones.
  • Desplaza la mano hacia arriba o abajo para moverte por las opciones.
  • Cierra el puño para seleccionar la opción enfocada.
  • Desplaza la mano hacia la derecha para retroceder / salir.
