# p2-sistemas-interactivos-y-ubicuos

## Requisitos
- Node.js instalado

## Instalación
npm install

## Ejecución
npm start

## Acceso
- Pantalla principal: http://localhost:3000/pantalla.html
- Mando móvil: http://localhost:3000/mando.html

## Pruebas en móvil
Si el móvil y el ordenador están en la misma red Wi-Fi, usar:
http://IP_DEL_SERVIDOR:3000/mando.html

## Notas
- No usar Live Server.
- La comunicación entre clientes se realiza con Socket.IO.
- La carpeta `public` contiene los archivos cliente.
